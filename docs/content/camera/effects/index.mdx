Effectsはカメラの構図を変えずに、揺れやブラーを加えます。<code>SceneStage</code>のカメラ設定で、Movesと組み合わせて使えます。

| Effect                                                       | 見え方                                             | 合う場面                                                                       |
| ------------------------------------------------------------ | -------------------------------------------------- | ------------------------------------------------------------------------------ |
| [<code>HandheldDrift</code>](/camera/effects/handheld-drift) | 手持ちカメラのような小さな揺れをゆっくり加えます。 | 長い静かなカットに自然な揺らぎを添えたい場面に向いています。                   |
| [<code>ShakeOnBeat</code>](/camera/effects/shake-on-beat)    | 指定した拍に合わせて、カメラを短く揺らします。     | キックやスネア、歌詞の強いアクセントを画面の揺れで補いたい場面に向いています。 |
| [<code>WhipBlur</code>](/camera/effects/whip-blur)           | 速いカメラ移動にブラーを加え、勢いを強調します。   | WhipPanなどの速いカメラ移動と同じタイミングで使うと効果的です。                |

Movesで構図を変え、Effectsで揺れやブラーを加えます。
