カメラの構図を変える演出です。各Moveはフレーム位置と長さを持ち、<code>SceneStage</code>のカメラトラックに設定します。

| Move                                                      | 動き                                                         | 合う場面                                                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| [<code>MoveTo</code>](/camera/moves/move-to)              | 指定した構図へ、なめらかに移動します。                       | Verseなど、画をゆっくり見せたい区間や、人物・小物へ自然に視線を導く場面に向いています。          |
| [<code>SnapZoom</code>](/camera/moves/snap-zoom)          | 注目点へ一気に寄り、少し行き過ぎてから戻ります。             | キーワードの登場、感情の切り替わり、強い音のアクセントなど、ここを見てほしい瞬間に向いています。 |
| [<code>WhipPan</code>](/camera/moves/whip-pan)            | カメラを勢いよく振り、目標位置を少し通り過ぎてから止めます。 | 画面内の視線を移す場面や、強い拍、次の見せ場への切り返しに向いています。                         |
| [<code>TracePath</code>](/camera/moves/trace-path)        | 複数の注目点を順番になぞるように移動します。                 | 絵の中に視線を導く流れや、人物・小物の関係があるときに向いています。                             |
| [<code>DiveAndGlide</code>](/camera/moves/dive-and-glide) | 最初の注目点へ急接近し、その後は経路に沿って移動します。     | 曲が盛り上がる場面で画に一気に寄り、その後も長く視線を動かしたいときに向いています。             |
| [<code>TiltReveal</code>](/camera/moves/tilt-reveal)      | 画面の傾きを水平に戻しながら、注目点を見せます。             | シーンの冒頭で不安定な印象を出してから、落ち着いた構図に移りたいときに向いています。             |
| [<code>DutchRoll</code>](/camera/moves/dutch-roll)        | 画面を左右に傾けて揺らし、最後に水平へ戻します。             | 迷いや揺らぎを短く表したい場面に向いています。                                                   |
| [<code>CutTo</code>](/camera/moves/cut-to)                | カメラの構図を瞬時に切り替え、そのまま保ちます。             | 強い拍や歌詞の切れ目など、カメラの構図を瞬時に変えたい場面に向いています。                       |
| [<code>Stutter</code>](/camera/moves/stutter)             | 複数の構図を短い間隔で切り替えます。                         | 細かいリズムのアクセントや、断片的・躍動的な見せ方に向いています。                               |
