カメラの機能は、構図自体を変える**Moves**と、現在の構図に質感を足す**Effects**に分かれます。

- [Moves](/camera/moves)：ズーム、パン、回転、経路移動、カット
- [Effects](/camera/effects)：手持ち感、拍に合わせた揺れ、短いブラー

時間はフレームで指定します。歌の強弱に沿ってカメラの動きを選び、強い演出の後には画を見せる間を取ります。
