## API Reference

| Prop       | Type     | Default   | Description                              |
| ---------- | -------- | --------- | ---------------------------------------- |
| `color`    | `string` | `#f2f4f3` | 霧の色。                                 |
| `density`  | `number` | `0.34`    | 霧の濃さ。0から1。                       |
| `speed`    | `number` | `0.055`   | 漂う速度。1秒あたりの周期数。`0`で静止。 |
| `softness` | `number` | `24`      | ぼかし半径。ピクセル単位。               |
