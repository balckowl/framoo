## API Reference

| Prop      | Type     | Default   | Description                        |
| --------- | -------- | --------- | ---------------------------------- |
| `color`   | `string` | `#000000` | 画面全体に重ねる色。CSS color。    |
| `opacity` | `number` | `0.28`    | 重ねるレイヤーの不透明度。0から1。 |
