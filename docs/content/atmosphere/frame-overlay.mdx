## API Reference

| Prop        | Type     | Default   | Description                            |
| ----------- | -------- | --------- | -------------------------------------- |
| `inset`     | `number` | `56`      | 画面端から枠までの距離。ピクセル単位。 |
| `thickness` | `number` | `2`       | 線の太さ。ピクセル単位。               |
| `color`     | `string` | `#ffffff` | 枠線の色。                             |
| `opacity`   | `number` | `0.9`     | 枠線の不透明度。0から1。               |
| `radius`    | `number` | `0`       | 角丸の半径。ピクセル単位。0は直角。    |
