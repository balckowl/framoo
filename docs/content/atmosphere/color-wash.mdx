## API Reference

| Prop                    | Type             | Default        | Description                        |
| ----------------------- | ---------------- | -------------- | ---------------------------------- |
| `from`                  | `string`         | —              | グラデーションの1色目。CSS color。 |
| `to`                    | `string`         | —              | グラデーションの2色目。CSS color。 |
| `opacity`               | `number`         | `0.32`         | 重ねるレイヤーの不透明度。0から1。 |
| `cycleDurationInFrames` | `number`         | 省略時は12秒分 | 色が往復する1サイクルの長さ。      |
| `blendMode`             | `CSS blend mode` | `normal`       | 背面のレイヤーとの合成方法。       |
